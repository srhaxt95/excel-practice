📖 บทเรียน: การแยกข้อความด้วย LEFT, MID, FIND

โครงสร้างอีเมล: name.lastname@provider.com

  • หาจุดอ้างอิง: ใช้ FIND(".", เซลล์) เพื่อหาตำแหน่งจุด และ FIND("@", เซลล์) หาตำแหน่ง @
  • ตัดข้อความ:
    =LEFT(A2, FIND(".", A2) - 1) → ดึงชื่อหน้าจุด
    =MID(A2, FIND(".", A2) + 1, FIND("@", A2) - FIND(".", A2) - 1) → ดึงนามสกุลระหว่างจุดกับ @
    =MID(A2, FIND("@", A2) + 1, LEN(A2)) → ดึง Provider ด้านหลัง @ ทั้งหมด
แบบฝึกหัดสุ่มโจทย์

โจทย์: จงเขียนสูตรในช่อง C2 (lastname) สำหรับข้อมูลอีเมลด้านล่างนี้

A (email)B (name)C (lastname)D (email provider)
mio.aki@yahoo.com mio [ ใส่สูตรที่นี่ ] yahoo.com

📖 บทเรียน: IF ซ้อน IF และการล็อกเซลล์ ($)

เมื่อต้องตรวจสอบเงื่อนไขหลายระดับ ให้เขียนไล่ลำดับอย่างเป็นระเบียบ:

=IF(วันลา <= 5, เงินเดือน * $E$2, IF(วันลา <= 10, เงินเดือน * $E$3, เงินเดือน * $E$4))

💡 ทริกสำคัญ: ต้องใส่เครื่องหมาย $ ล็อกแถวของช่องเปอร์เซ็นต์ (เช่น $E$2) เพื่อไม่ให้ตำแหน่งเลื่อนเมื่อลากสูตร

แบบฝึกหัดสุ่มโจทย์

โจทย์: จงเขียนสูตรคำนวณเงินโบนัส (บาท) ในเซลล์ C6 ตามข้อมูลพนักงานที่สุ่มได้

ตารางเกณฑ์โบนัสอ้างอิง
<= 5 วัน ($E$2)10% ของเงินเดือน
6-10 วัน ($E$3)7.50% ของเงินเดือน
> 10 วัน ($E$4)3% ของเงินเดือน
A (ชื่อ)B (วันลา)C (bonus)D (เงินเดือน)
john 5 [ ใส่สูตรที่นี่ ] 20000

📖 บทเรียน: การตัดเกรดหลายชั้น & ฟังก์ชัน OR

  • การตัดเกรด (GRADE): ใช้ IF ซ้อนกันโดยไล่จากคะแนนสูงไปต่ำ
    =IF(A8>=70, "A", IF(A8>=61, "B", IF(A8>=51, "C", IF(A8>=41, "D", "F"))))
  • การแจ้งเตือน (REMARK): ถ้าเกรดเป็น D หรือ F ให้ขึ้น "Regrade"
    =IF(OR(B8="D", B8="F"), "Regrade", "")
แบบฝึกหัดสุ่มโจทย์

โจทย์: คะแนนดิบในช่อง A8 = 85

A (คะแนน)B (GRADE)C (REMARK)
85 [ พิมพ์สูตรตัดเกรด ] เว้นว่างไว้ก่อน
